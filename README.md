# Thunder·HUB 启动台

> AI 时代，每个人桌面上都躺着一堆 bat——Thunder·HUB 把它们收进来、分好类、一键启动。

## 为什么会有这个

AI 越来越强，越来越多人开始 vibe coding，做出各种小工具、小智能体——而它们大多以 `.bat` 双击的方式启动。

做得多了，问题就来了：桌面和文件夹里全是长得一模一样的 bat 图标，每次想打开某个工具，都要靠文件名挨个找。

Thunder·HUB 就是为这件事做的：**把做好的 bat（以及程序、快捷方式、文件夹、网址）都收进来，分好类，之后按一个全局快捷键呼出界面，找到、点击、打开**——触手可及。

一个运行在 Windows 上的轻量本地启动器：双击一个 `.bat` 就打开一个无边框程序窗口，不用时收进系统托盘。界面是奶油纸 × 黑墨 × 红印章的纸感贴纸风。

## 功能一览

- **一键收藏**：点击添加 / 系统文件选择器 / **直接把文件、快捷方式、文件夹拖进窗口**
- **真实图标**：自动提取 exe、快捷方式的程序图标
- **分类侧边栏**：新建 / 改名 / 删除分类，拖卡片归类，侧边栏可收起成图标栏
- **卡片管理**：点击启动、双击名称内联改名、右键菜单（打开所在位置 / 移到分类 / 移除）、拖拽排序
- **系统托盘**：关闭窗口只是收进托盘，右键托盘图标可再次打开或彻底退出
- **全局热键**：默认 `Alt+D` 呼出/隐藏，**支持自定义任意组合键**（按键录制）
- **开机自启动**：设置里一键开关（写入系统启动文件夹）
- **细节体验**：搜索过滤、窗口尺寸位置记忆、尊重系统"减少动态效果"偏好
- **多语言**：中文 / English 一键切换（标题栏语言按钮），偏好自动记忆
- **新手指引**：首次打开自动播放四步上手导览（设置里可重看）

## 快速开始

### 环境要求

- Windows 10 / 11（自带 Edge WebView2 运行时即可，绝大多数系统已内置）
- Python 3.10+（[官网下载](https://www.python.org/downloads/)，安装时勾选 **Add to PATH**）

### 运行

```
双击 Thunder Hub.bat
```

首次运行会自动安装依赖（`pywebview` / `pystray` / `pillow`），之后双击即用、无黑窗。

## 使用速查

| 操作 | 方式 |
| --- | --- |
| 添加收藏 | 按 `A`，或直接把文件拖进窗口 |
| 启动 | 单击卡片 / `Enter` 启动搜索结果第一项 |
| 搜索 | 按 `/` 聚焦搜索框 |
| 重命名 | 双击卡片名称 |
| 更多操作 | 右键卡片（打开所在位置、移到分类、移除） |
| 排序 | 拖拽卡片 |
| 归类 | 把卡片拖到左侧分类上 |
| 呼出 / 隐藏 | `Alt + D`（可在设置中自定义） |
| 收起侧边栏 | 侧边栏右上角按钮 |

## 设置

标题栏齿轮打开设置面板：

- **开机自动启动**：登录 Windows 后自动驻留托盘
- **启动时只驻留托盘**：打开程序不弹窗，`Alt+D` 随叫随到
- **全局热键**：开关 + 自定义组合键（改动重启后生效）
- **关闭窗口时直接退出**：默认关闭只是收进托盘

## 项目结构

```
Thunder Hub.bat        入口（自举：探测 Python、自动装依赖、静默启动）
server.py          本地服务 + 窗口/托盘/热键/图标提取（仅标准库 + 三个依赖）
icons.ps1          exe / lnk 图标提取（PowerShell）
app/
  index.html       界面结构
  style.css        纸感贴纸风样式
  app.js           全部前端交互
requirements.txt   依赖声明
```

数据文件 `launcher-data.json`（收藏、分类、设置）保存在程序目录，纯文本可直接备份。

## 常见问题

**Q: 双击 bat 提示找不到 Python？**
安装 Python 3.10+ 并勾选 Add to PATH，或安装后重开终端再试。

**Q: 窗口打不开 / 提示 WebView2 相关错误？**
少数精简版系统缺少 WebView2 运行时，到[微软官网](https://developer.microsoft.com/microsoft-edge/webview2/)下载安装即可；程序检测到异常会自动回退为浏览器窗口模式。

**Q: 热键没反应？**
组合键被其他程序占用时会静默失效，到设置里换一组；改动热键后需要重启程序生效。
